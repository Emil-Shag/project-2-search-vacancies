# Поиск вакансий с hh.ru (Курсовая работа №2)

## Описание проекта

Данный проект представляет собой консольное приложение для поиска вакансий с сайта **hh.ru**  
Приложение получает данные через публичное API hh.ru, обрабатывает их, сохраняет в файл и предоставляет пользователю удобный интерфейс для взаимодействия через консоль.

Проект реализован в рамках учебного задания и демонстрирует:
- работу с внешним API;
- применение принципов ООП;
- использование абстрактных классов;
- обработку данных и сохранение их в файл JSON;
- реализацию пользовательского интерфейса в консоли.

---

## Функциональность

Пользователь может:

- ввести поисковый запрос для получения вакансий с hh.ru;
- получить **топ N вакансий по уровню зарплаты**;
- выполнить **поиск по ключевому слову в описании вакансий**;
- сохранить найденные вакансии в файл `vacancies.json`;
- выйти из программы через явное меню.

---

## Архитектура проекта

### Работа с API
- Используется абстрактный класс `AbstractApi`
- Реализация для hh.ru — класс `HhRu`
- Метод подключения к API (`__connect_api`) является **приватным**
- Публичный метод `connect_api()` реализован согласно требованиям задания

### Работа с вакансиями
- Каждая вакансия представлена объектом класса `Vacancy`
- Реализована валидация данных
- Поддерживается сравнение вакансий по зарплате
- Для сохранения используется метод `to_dict()`

### Работа с файлами
- Используется абстрактный класс `AbstractFiles`
- Реализация — `JsonFiles`
- Вакансии сохраняются в папку `data/`
- Исключается дублирование вакансий по URL

## Пользовательский интерфейс

Взаимодействие с пользователем осуществляется через консоль:

- `1 — Найти вакансии`
- `2 — Выйти из программы`
